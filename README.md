## What's in here

- `index.html` — the ad page itself: one self-contained file, no build step, no external assets.
- `ad.png` — a screenshot of the page with the invite link visible.
- `LICENSE` — MIT.

## Run it

Open `index.html` in any browser, or serve the folder:

```sh
python3 -m http.server 8000
```

## Why make.fun

- Bounties ship with starter kits: rules, scorer and the exact checks an entry must pass.
- Prizes are locked in escrow on Solana before a contest opens, and paid in USDC.
- Entries are graded and ranked in the open — deterministic scorers, judge panels, live leaderboards.
